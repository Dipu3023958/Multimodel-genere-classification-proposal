How to Run

-> Open final proposal.ipynb in Google Colab.

-> Select Runtime → Change runtime type → T4 GPU (or another available GPU).

-> Select Runtime → Run all.

-> The notebook will load the dataset, extract features, train the models and display the results.


Dataset

MM-IMDb: https://huggingface.co/datasets/pranavmr/MM-IMDb

Note

The pretrained EfficientNet-B0 and BERT models are kept frozen to reduce training cost.
